HelixNotes - portable for Windows
=================================

No installation needed. Unzip this folder anywhere (a USB drive works too) and
run HelixNotes.exe.

Everything the app stores - settings, the list of vaults, backups, the search
index, window size and position - is kept in the "data" folder created next to
HelixNotes.exe. Nothing is written to AppData or the registry.

Keep your vaults inside this folder, for example next to HelixNotes.exe, and the
app will find them even when the drive gets another letter.

To move or back up the app with your settings, copy the whole folder.
To remove it, delete the folder.

Requirements: Windows 10 or 11 with Microsoft Edge WebView2. Windows 11 always
includes it, and up-to-date Windows 10 does too. If the window stays blank,
install the "Evergreen" runtime from
https://developer.microsoft.com/microsoft-edge/webview2/

This build does not update itself: download a newer zip and replace
HelixNotes.exe, keeping the data folder.
